# 穿搭柜（Chuandagui）

一个纯前端的移动端穿搭管理 PWA，可「添加到主屏幕」像原生 App 一样使用。所有数据**仅保存在本机（IndexedDB），不上传任何服务器**，隐私安全。

## 功能

- **衣橱（首页）**：按 全部 / 春 / 夏 / 秋 / 冬 切换浏览；卡片网格（最新优先）；长按或点 `⋯` 可 **修改 / 删除**（删除有二次确认）；下拉刷新。
- **创建穿搭**：季节**多选必选**；备注选填；本地相册多图上传（预览 / 删除已选）；保存生成卡片（首图 = 第一张），可归到多个季节。
- **穿搭知识**：支持**分类**（默认：风格 / 配色 / 修身，可维护）；列表、新增 / 编辑 / 删除、详情；可**导出为 Word（.doc）** 知识库并分享。
- **全部照片导出**：一键打包为 `穿搭柜_全部穿搭_年月日时分.zip`，按「春季穿搭 / 夏季穿搭 / 秋季穿搭 / 冬季穿搭」分文件夹（无照片的季节自动跳过），可系统分享或本地下载。
- **PWA**：可安装到主屏幕、离线可用（Service Worker 缓存）、启动秒开。

## 技术栈

零依赖纯静态前端：

- `index.html` + `css/style.css` —— 移动优先 UI（渐变头部、毛玻璃底部导航、微交互动效）
- `js/db.js` —— IndexedDB 本地存储（含照片 Blob、知识分类）
- `js/zip.js` —— 自写 ZIP 打包器（STORE + CRC32，UTF-8 中文文件夹名）
- `js/word.js` —— 穿搭知识库导出 Word 兼容 `.doc`
- `js/app.js` —— 视图路由 + 三大模块全部交互逻辑
- `manifest.webmanifest` / `sw.js` / `icons/` —— PWA 安装与离线能力

## 本地运行

```bash
# 任意静态服务器即可，例如：
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123
```

> 注意：`http://127.0.0.1` 仅用于桌面预览；**添加到主屏幕 / PWA 安装必须 HTTPS**。

## 安装到手机（PWA）

- **iPhone（Safari）**：打开 HTTPS 地址 → 底部「分享」→「添加到主屏幕」→ 桌面出现「穿搭柜」图标，点开即全屏运行。
- **Android（Chrome）**：打开 HTTPS 地址 → 右上「⋯」→「安装应用 / 添加到主屏幕」。

## 打包成原生 App（可选）

若要上架 iOS / Android，可用 [Capacitor](https://capacitorjs.com/) 把这套静态资源套壳为原生应用，业务逻辑无需重写。

## 更新缓存

改动代码后，请把 `sw.js` 中的缓存名（如 `chuandagui-v1`）升一版，才能推送到已安装用户的设备。
